# A change-detection study of lexical and grammatical affixes in Kalaallisut

This repository contains experimental materials, data and analysis scripts from the Kalaallisut change-detection study.

## Repository Contents

- `R/` — Scripts for data processing and analyses.
- `data/` — The Kalaallisut change-detection data (licensed separately, see below).
- `research materials/` — The experiment script and experimental items.
